# Frigate Proxy — прототип главной страницы

Кликабельный прототип UX-редизайна главной frigate-proxy.ru. Данные примерные, оплата не проводится.

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Публикация на GitHub Pages идёт автоматически при пуше в `main`.
Решения и вопросы к владельцу — в [NOTES.md](NOTES.md).
